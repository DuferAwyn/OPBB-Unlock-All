Step 1: Download the github file into your downloads folder 

Step 2: Open Windows Powershell and paste the codes below in:

For all emblems & icons:

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\opbb_unlock_all.ps1" apply

For max in game currency (beli):

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\opbb_unlock_all.ps1" beli

REVERT ALL:

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\opbb_unlock_all.ps1" restore


NOTE: 
This DOES NOT unlock DLC character. There are often sales for the DLC. 
You must play about 5 missions in the main story to unlock online mode. Once you finish the Ivankov v Kuma mission everything should be available. 
You can purchase all characters (minus DLC) in Pirate Base once you do the max currency adjustment. 
All commands are ran in Windows Powershell
